## 建議使用方式

1. 新手先看「半導體就業百科入口」與「新手導覽」。
2. 想了解特定公司時，先看台積電，再看三星與 Micron 對照。
3. 撰寫新文章請先複製「公司 × Module 統一模板」。
4. 所有條目需遵循內容更新與品質流程，維持資訊可信度。
